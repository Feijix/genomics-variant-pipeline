# Benchmarks

Every figure below was produced by commit `e541b3b`, tag `v1.0-thesis`, and is
regenerated by:

```bash
bash test/run_sequential.sh
python3 test/compare_baselines.py --new test/results --baseline test/baselines
```

The committed baselines in `test/baselines/` are the values reported here. The
comparison script exits non-zero if a re-run produces different numbers.

All accuracy figures are chromosome 20 only. Whole-genome runs are reported in
[Scaling](#scaling) and measure cost, not accuracy: no whole-genome truth set
was applied.

## Structural variants

Truvari 5.4.0, `--passonly --sizemin 50 --sizemax 50000 --pctsize 0.7
--refdist 500 --pick single`, Q100 v1.1 chr20 (803 truth SVs).

Callsets are PASS-filtered before merging and before benchmarking. smoove
writes `.` rather than `PASS` in the FILTER column, so the filter accepts both.

Two matching regimes are reported. Strict is the primary figure; permissive is a
sensitivity analysis on the matching parameters.

| Regime | Callset | TP | FP | FN | Recall | Precision | F1 |
|---|---|---|---|---|---|---|---|
| strict (`--pctseq 0.7`) | Manta | 150 | 33 | 653 | 0.1868 | 0.8197 | 0.304 |
| | Delly | 61 | 48 | 742 | 0.0760 | 0.5596 | 0.134 |
| | smoove | 59 | 18 | 744 | 0.0735 | 0.7662 | 0.134 |
| | SURVIVOR union (≥1) | 153 | 78 | 650 | 0.1905 | 0.6623 | 0.296 |
| | SURVIVOR consensus (≥2) | 59 | 11 | 744 | 0.0735 | 0.8429 | 0.135 |
| permissive (`--pctseq 0 --dup-to-ins`) | Manta | 154 | 29 | 649 | 0.1918 | 0.8415 | 0.312 |
| | Delly | 64 | 45 | 739 | 0.0797 | 0.5872 | 0.140 |
| | smoove | 61 | 16 | 742 | 0.0760 | 0.7922 | 0.139 |
| | SURVIVOR union (≥1) | 158 | 73 | 645 | 0.1968 | 0.6840 | 0.306 |
| | SURVIVOR consensus (≥2) | 61 | 9 | 742 | 0.0760 | 0.8714 | 0.140 |

Neither ensemble exceeds the best single caller's F1 in either regime. The
union gains 3 true positives over Manta and adds 45 false positives (strict);
the consensus has the highest precision in the table and the recall of the
weakest single caller.

### Truth-set composition

Of the 803 scored truth SVs, 255 are deletions and 548 are insertions. smoove
(LUMPY) does not call insertions and Delly calls few, so their maximum
achievable recall against this truth set is 255/803 = 31.8 %, independent of
sensitivity. Manta's per-type recall is 35.3 % for deletions and 10.9 % for
insertions.

Delly emits 176 symbolic duplications and 198 inversions among its PASS
records; the truth set contains neither type. Converting duplications to
insertions (`--dup-to-ins`, permissive regime) gains 3 true positives.

filtered inputs: Manta 286, Delly 832, smoove 322 PASS records):

|---|---|---|
| 111 | all three | 87 |

## Scaling

Germline path, HG001, three nested extents. The three runs differ only in the
region argument; sample, alignment, reference and configuration are identical.

| | chr20 (64 Mb) | chr1–4 (879 Mb) | whole genome (3.1 Gb) |
|---|---|---|---|
| DeepVariant wall | ~35 min | 4 h 18 m | 12 h 52 m |
| DeepVariant peak RSS | ~13 GB | 12.7 GB | 17.4 GB |
| VEP wall / peak RSS | — | 1 h 11 m / 1.9 GB | 4 h 48 m / 2.4 GB |
| BFF conversion wall / peak RSS | — | 52 m / 5.2 GB | 3 h 12 m / 5.8 GB |
| Variants called | 78 973 | 1 252 116 | 4 817 291 |
| Ts/Tv | 2.17 | 1.95 | 1.98 |

48× more sequence than chr20 gives ~22× the runtime and 1.4× the peak memory.

Structural-variant callers, whole genome:

| Caller | Wall | Peak RSS |
|---|---|---|
| Manta | 3 h 29 m | 635 MB |
| Delly | 3 h 21 m | 1.3 GB |
| smoove | 27 m | 4.6 GB |
| SURVIVOR | 10.5 s | 90 MB |

### Determinism

The whole-genome germline run was executed twice, independently, with an
intervening pipeline modification that invalidated the resume cache. Both runs
produced 4 817 291 records (3 913 012 SNVs, 910 282 indels) at Ts/Tv 1.98.
DeepVariant wall-clock differed by 0.6 % and peak memory was identical.

Structural-variant results vary by at most one call in approximately 180
(±0.5 % precision) across runs: Manta's strict false-positive count was 33, 33,
32, 33, 33 over five executions of an identical configuration.

### BFF conversion cost

| Extent | Wall | Peak RSS | Bytes written | Output | Amplification |
|---|---|---|---|---|---|
| chr1–4 | 52 m | 5.2 GB | 20.9 GB | 121 MB | ~128× |
| whole genome | 3 h 12 m | 5.8 GB | 77.8 GB | 441 MB | ~180× |

The converter materialises uncompressed JSON before compression, so the
transient footprint grows with variant count while the compressed output does
not. At genome scale the transient exceeds the input alignment, making BFF
conversion the storage-binding stage.

## Catalogue validation

`bff-tools validate`, reference-implementation schemas.

**genomicVariations, whole genome:** 4 817 282 of 4 817 291 records pass. The 9
failures carry a duplicated ClinVar identifier (`clinvar:126297,126297`) written
by `bff-tools` itself, which its own schema pattern `^(clinvar:)?\d+$` rejects.
Validation of the 7.5 GB uncompressed catalogue took approximately 3 h 40 m.

**Metadata entities, from EGA dataset EGAD00001000082:** 5 of 6 entities pass.

| Entity | Records | Result |
|---|---|---|
| datasets | 1 | pass |
| cohorts | 1 | pass |
| individuals | 28 | pass |
| runs | 100 | pass |
| analyses | 100 | pass |
| biosamples | 42 | fail — `sampleOriginType` |

Fields requiring a value not derivable from the EGA record:

| Field | EGA holds | Class |
|---|---|---|
| `sampleOriginType` | — | no value; anatomical term (UBERON) |
| `librarySource.id` | `"GENOMIC"` | value present, ontology code absent |
| `platformModel.id` | `"Illumina Genome Analyzer II"` | value present, ontology code absent |
| `diseases.diseaseCode.id` | `"Breast Cancer"` | value present, ontology code absent |
| `runDate`, `analysisDate` | — | no value |
| `pipelineName` | — | supplied by the pipeline |

`cohortType` is a three-value enumeration (`study-defined`, `beacon-defined`,
`user-defined`) describing how a cohort was constituted. EGA's `study_type`
("Cancer Genomics") describes the research domain; the two do not correspond.
